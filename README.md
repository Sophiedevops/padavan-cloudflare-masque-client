# Cloudflare MASQUE Client for Padavan (Usque)

Неофициальный скрипт для автоматической установки и настройки клиента **Cloudflare MASQUE** на роутерах с прошивкой **Padavan**. Решение оптимизировано для работы в условиях ограниченных ресурсов и обеспечивает обход блокировок с использованием современных протоколов.

## ✨ Основные особенности

  * **Stealth Watchdog:** Умный «сторожевой кот», который проверяет соединение через случайные промежутки времени (3–9 минут), не создавая лишней нагрузки.
  * **Hybrid Protocols:** Автоматическое переключение между **HTTP/3 (UDP)** и **HTTP/2 (TCP)**, если провайдер блокирует один из протоколов.
  * **Post-Quantum Security:** Использование гибридного шифрования **X25519MLKEM768 (Kyber)** осуществляет сам Cloudflare.
  * **Bilingual Interface:** Поддержка английского и русского языков в консоли при установке.
  * **Resilience:** Скрипт «бьется до победного» — при потере связи он будет бесконечно пытаться восстановить туннель.

### Аппаратные ограничения

Протокол MASQUE создает высокую нагрузку на центральный процессор из-за сложного шифрования.

  * **На процессорах MT7620A:** Тяжелый контент (IPTV, Torrents, Raw Streams в 4K UHD) иногда может вызывать **100% нагрузку CPU** и кратковременные фризы.
  * **YouTube:** Работает стабильно даже в высоком качестве, так как использует технологию буферизации (загрузка видео порциями).
  * **Обычный контент:** HD и Full HD видео (720p/1080p) воспроизводятся без проблем.

## 🚀 Установка

Для установки выполните следующую команду в терминале роутера (SSH):

```bash
wget -qO /tmp/install.sh https://raw.githubusercontent.com/Sophiedevops/padavan-cloudflare-masque-client/main/install.sh && chmod +x /tmp/install.sh && /tmp/install.sh
```

### Что делает скрипт:

1.  Проверяет наличие раздела `/opt` (Entware).
2.  Скачивает и регистрирует бинарный файл `usque`.
3.  Создает службу автозапуска `/opt/etc/init.d/S99usque`.
4.  Настраивает скрытый мониторинг (Watchdog).
5.  Прописывает скрипт в NVRAM роутера для сохранения после перезагрузки.

## ⚙️ Использование

После установки прокси будет доступен по адресу вашего роутера (по умолчанию `192.168.1.1`) на порту **1090**.

### Настройка клиентов:

  * **Тип прокси:** SOCKS5
  * **Адрес:** `192.168.1.1` (IP роутера)
  * **Порт:** `1090`

### Управление службой:

  * `S99usque start` — запустить сервис.
  * `S99usque stop` — остановить сервис.
  * `S99usque restart` — перезапустить (включая Watchdog).
  * `S99usque status` — проверить состояние процесса.
